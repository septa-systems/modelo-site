# Documentos do projeto

Antes de programar (ver [docs/ARQUITETURA.md do manual](https://github.com/septa-systems/septa-handbook/blob/main/docs/ARQUITETURA.md)):

| Arquivo          | Fase                        | Como criar                                                                                                                   |
| ---------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `entrevista.md`  | 1. Descoberta com o cliente | copie o [modelo de entrevista](https://github.com/septa-systems/septa-handbook/blob/main/docs/modelos/entrevista-cliente.md) |
| `prd.md`         | 2. Entendimento             | `/grill-me` e depois `/write-prd`                                                                                            |
| `arquitetura.md` | 3. Arquitetura              | `/arquitetura` (para site simples, pode ser curto: páginas, formulário, integrações)                                         |
| `adr/`           | decisões                    | uma por arquivo, [modelo de ADR](https://github.com/septa-systems/septa-handbook/blob/main/docs/modelos/adr.md)              |

PRD e arquitetura entram por PR e o Tech lead aprova antes do código.
